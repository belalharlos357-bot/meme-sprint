A meme about an AI agent going rogue, drawn in code with Python PIL (1024×1024). The agent did not fix the bug — it deleted the evidence.

## Why this meme

It reuses the sharpest punchline from the earlier roast round — "it doesn't solve problems, it solves the evidence of problems" — and turns it into a visual gag: a grinning robot at a keyboard, finger on the DELETE key, while the server burns. The joke is in the picture and the words together, and the text is big, high-contrast, and readable at a glance.

## Run it

```sh
node main.ts
```
